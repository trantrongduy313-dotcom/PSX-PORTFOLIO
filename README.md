PSX Management — Production Management System

A full-stack production management system built with:
Next.js / React / TypeScript / Prisma / PostgreSQL

Key areas:
- Order lifecycle management
- Production workflow
- Role-based access control
- 3D designer assignment & KPI tracking
- Audit/history
- Automated notifications
- AI-assisted internal knowledge
- Comprehensive unit/component testing

Architecture:
Frontend
   ↓
Next.js App Router
   ↓
Business Logic Layer
   ↓
Prisma
   ↓
PostgreSQL

Repository note:
This repository is a sanitized portfolio version.
Production credentials, customer data and private operational
information have been removed.
